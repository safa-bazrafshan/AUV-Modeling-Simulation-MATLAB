# AUV Modeling & Simulation in MATLAB

MATLAB-based modeling and simulation of Autonomous Underwater Vehicles (AUVs), developed as part of the **AUV Modeling & Simulation in MATLAB** YouTube series.

## About This Repository

This repository contains the MATLAB scripts developed throughout the AUV Modeling & Simulation series.

The goal of this series is to build an AUV mathematical model step by step, starting from basic motion and 6-DOF kinematics and gradually introducing underwater dynamics, hydrodynamic forces, thruster modeling, and complete AUV simulation.

The emphasis is on understanding the engineering concepts behind the equations and implementing them directly in MATLAB.

## YouTube Series

**AUV Modeling & Simulation in MATLAB**

The series follows this general progression:

1. 6-DOF Kinematics
2. Rotation and Transformation
3. Underwater Dynamics
4. Hydrodynamic Forces
5. Added Mass
6. Drag and Damping
7. Buoyancy and Restoring Forces
8. Thruster Modeling
9. Complete AUV Dynamic Model
10. Numerical Simulation
11. 3D Trajectory Visualization
12. Complete AUV Simulation


## Modeling Approach

The series follows an engineering workflow:

**Engineering Concept → Mathematical Model → MATLAB Implementation → Simulation → Results → Analysis**

The models are implemented primarily using MATLAB scripts and standard MATLAB functionality, with minimal dependence on specialized toolboxes.

## Prerequisites

A basic understanding of:

- MATLAB programming
- Basic mathematics
- Coordinate frames
- AUV fundamentals
- Basic engineering concepts

is recommended.
